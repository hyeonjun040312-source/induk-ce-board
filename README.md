# 🎓 인덕대학교 컴퓨터전자공학과 웹 게시판 시스템
> **INDUK UNIVERSITY Department of Computer & Electronic Engineering Board System**

인덕대학교 컴퓨터전자공학과 구성원(재학생 및 학과 관리자)을 위한 풀스택 웹 게시판 애플리케이션입니다.  
Node.js, Express, SQLite3(내장 JSON 파일 DB 자동 Fallback 지원), EJS 템플릿 엔진을 기반으로 구축되었습니다.

---

## 📌 주요 특징 및 기능 구현 현황

### 1. 회원 및 인증 (로그인/회원가입)
- **간편한 가입 및 로그인**: 이메일/문자 등 복잡한 본인인증 없이 아이디, 비밀번호, 이름만으로 즉시 가입 가능
- **비밀번호 단방향 암호화**: `bcryptjs` 해싱을 통한 사용자 패스워드 안전 암호화 보관
- **세션 기반 인증 유지**: `express-session`을 활용하여 로그인 상태 유지 및 안전한 세션 관리
- **테스트 편의성**: 로그인 화면에서 원클릭으로 관리자/학생 계정을 자동 입력할 수 있는 퀵 버튼 제공

### 2. 게시글 CRUD (작성, 조회, 수정, 삭제)
- **목록 화면**: 등록된 글 번호, [공지] 배지, 제목, 작성자, 작성일시, 조회수, 첨부파일 아이콘, 댓글 수 표시
- **검색 및 페이징**: 제목, 내용, 작성자 대상 통합 검색 및 페이지네이션 (10개씩)
- **상세 페이지**: 
  - 본문 서식 보존 (줄바꿈)
  - 첨부파일 영역: 파일명, 용량 표시 및 안전한 다운로드 기능 (`res.download`)
  - 이미지 파일(JPG, PNG, GIF, WEBP)의 경우 본문 상단에 인라인 이미지 미리보기 지원
  - 하단 댓글 목록 조회, 실시간 댓글 작성 및 삭제 기능
- **작성/수정 폼**:
  - 제목, 본문 작성 및 파일 첨부 (최대 20MB)
  - 관리자 계정일 경우 **"학과 공지사항으로 등록"** 체크박스 활성화
  - 수정 시 기존 파일 유지/삭제/새 파일 교체 옵션 제공

### 3. 권한 관리 및 핵심 보안 (403 Forbidden 통제)
- **일반 학생 권한**:
  - 게시글 작성, 조회, 본인이 작성한 게시글의 수정 및 삭제, 댓글 작성/삭제 가능
- **타인 글 철저 보호**:
  - 화면 UI: 타인의 글이나 댓글에는 수정/삭제 버튼이 **아예 노출되지 않음**
  - 백엔드 미들웨어 검증: URL 직접 호출(`/board/:id/edit`, `/board/:id/delete`, `/board/comments/:id/delete`) 시 작성자 ID와 세션 사용자 ID를 서버 사이드에서 엄격히 검증하여 일치하지 않으면 **`403 Forbidden` (접근 권한 없음)** 에러 페이지를 반환하고 완벽히 차단
- **학과 관리자(Admin) 권한**:
  - 학과 공지사항 등록 및 상단 고정
  - 부적절한 게시글 및 댓글 강제 삭제
  - 관리자 전용 대시보드 페이지(`/admin`) 접근 권한

### 4. 관리자 전용 관리 센터 (`/admin`)
- **통계 대시보드**: 등록 회원 수, 전체 게시글 수, 학과 공지사항 수, 전체 댓글 수 요약 카드
- **회원 관리**: 전체 회원 목록 조회, 학생 ↔ 관리자 역할(Role) 즉각 변경, 악성 회원 강제 탈퇴 처리 (본인 계정 삭제 방지)
- **게시글 및 공지 관리**: 전체 글 목록, 일반글 ↔ 공지글 전환 토글, 부적절한 글 관리자 권한 즉각 삭제

## 🚀 실행 방법

### 1. 패키지 설치
프로젝트 루트 디렉토리(`induk-ce-board`)로 이동한 후 필요한 패키지를 설치합니다:

```bash
cd induk-ce-board
npm install
```

> **참고 (안정성)**:  
> 본 프로그램은 Node.js 네이티브 환경에 맞춰 `better-sqlite3` 대신 컴파일 오류가 적은 `sqlite3`와 순수 JS 기반 `bcryptjs`를 적용했습니다.  
> 추가로 C++ 컴파일러가 없는 특수 환경에서도 즉시 100% 실행되도록 `database/db.js` 내에 **내장 JSON 파일 DB 자동 Fallback 엔진**이 완벽히 장착되어 있어, 별도의 빌드 오류 걱정 없이 바로 구동됩니다.

### 2. 서버 실행
```bash
npm start
```
또는 개발 모드:
```bash
node server.js
```

### 3. 브라우저 접속
웹 브라우저를 열고 아래 주소로 접속합니다:
👉 **`http://localhost:3000`**

## 🔑 테스트용 초기 기본 계정 안내

서버가 최초 실행될 때 `database/db.js`의 초기화 로직에 의해 아래 계정과 기본 공지사항, 샘플 게시글 및 댓글이 **자동으로 생성(Seed)**됩니다.

| 구분 | 아이디(username) | 비밀번호(password) | 이름 | 역할(Role) | 권한 및 기능 |
|:---:|:---:|:---:|:---:|:---:|:---|
| **학과 관리자** | `admin` | `admin1234` | 학과사무실(관리자) | `admin` | 학과 공지사항 작성, 관리자 센터 접근(`/admin`), 부적절한 게시글/회원 관리 |
| **일반 학생 1** | `student1` | `student1234` | 김인덕 | `student` | 게시글 작성, 댓글 작성, 본인 글/댓글 수정·삭제 (타인 글 수정 불가) |
| **일반 학생 2** | `student2` | `student1234` | 전자 | `student` | 게시글 작성, 댓글 작성, student1 글 수정/삭제 시도시 403 차단 검증용 |

## 🛡️ 권한 검증 및 보안 테스트 시나리오

1. **타인 글 수정/삭제 차단 검증 (403 Forbidden)**
   - `student2`로 로그인합니다.
   - `student1`이 작성한 게시글에 접속합니다.
   - 화면에 [수정], [삭제] 버튼이 보이지 않는 것을 확인합니다.
   - 주소창에 직접 `/board/2/edit` 또는 POST 요청을 강제로 전송하더라도, 백엔드 `isPostOwnerOrAdmin` 미들웨어가 감지하여 **`403 Forbidden (접근 권한 없음)`** 에러 화면으로 즉시 차단합니다.

2. **관리자 페이지 접근 차단 검증**
   - 일반 학생(`student1`)으로 로그인한 상태에서 `/admin`에 접속을 시도하면 `isAdmin` 미들웨어에 의해 **`403 Forbidden`**으로 즉각 차단됩니다.
   - 관리자(`admin`)로 로그인 시 상단 네비게이션에 [관리자 페이지] 메뉴가 활성화되고 접근이 허용됩니다.

3. **파일 다운로드 보안 (Path Traversal 방지)**
   - 첨부파일 다운로드 시 `path.basename`을 통해 상위 경로(`../`) 탐색 공격을 원천 차단하고 원본 한글 파일명으로 온전히 저장 및 전송됩니다.
